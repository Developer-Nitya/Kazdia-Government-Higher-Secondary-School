কাজদিয়া সরকারি উচ্চ মাধ্যমিক বিদ্যালয় - এডমিন প্যানেল নির্দেশনা

১) এডমিন প্যানেল কোথায় পাবেন
- হোস্টিংয়ের মূল public_html ফোল্ডারে ফাইল আপলোড করলে:
  https://your-domain.com/admin/

- shed_homepage_design ফোল্ডারসহ আপলোড করলে:
  https://your-domain.com/shed_homepage_design/admin/

২) লগইন
- ডিফল্ট পাসওয়ার্ড backend/config.php ফাইলে SCHOOL_ADMIN_PASSWORD নামে আছে।
- লাইভ হোস্টিংয়ে আপলোডের আগে পাসওয়ার্ড অবশ্যই পরিবর্তন করুন।

৩) প্রতিষ্ঠান প্রধানদের তথ্য
- এডমিন প্যানেলে লগইন করার পর “সাবেক প্রতিষ্ঠান প্রধানগণ” কার্ডে ক্লিক করুন।
- সেখানে ক্রমিক নং, নাম, পদবী, মেয়াদকাল, সংক্ষিপ্ত পরিচিতি এবং ছবি আপলোড করা যাবে।
- ফ্রন্টেন্ড তালিকা দেখতে মেন্যু থেকে “সাবেক প্রতিষ্ঠান প্রধানগণ” ক্লিক করলে নতুন ট্যাবে ওপেন হবে।

৪) জাতীয় সংগীত আপলোড/পরিবর্তন
- এডমিন প্যানেলে লগইন করার পর “জাতীয় সংগীত” কার্ডে ক্লিক করুন।
- সেখানে MP3/OGG/WAV অডিও অথবা MP4/WEBM/OGV ভিডিও আপলোড করা যাবে।
- নতুন ফাইল আপলোড করলে হোমপেজের “জাতীয় সংগীত” বক্সে সেটি বাজবে।
- প্রয়োজনে “অফিসিয়াল সোর্সে রিসেট করুন” বাটনে ক্লিক করলে জাতীয় সংগীতের ডিফল্ট অফিসিয়াল সোর্স আবার সেট হবে।

৫) হোস্টিং সেটআপ
- PHP-enabled hosting দরকার।
- MySQL ডাটাবেজ দরকার নেই।
- storage/, uploads/former-heads/ এবং uploads/media/ ফোল্ডারে write permission থাকতে হবে।


===============================
নতুন সম্পূর্ণ CMS প্যানেল
===============================

Admin dashboard থেকে "সম্পূর্ণ ওয়েবসাইট কনটেন্ট" খুলুন অথবা সরাসরি:
admin/content.php

এখান থেকে এডিট করা যাবে:
- প্রতিষ্ঠানের মূল তথ্য, লোগো, ব্যানার
- হোমপেজ স্লাইডার, শিক্ষার ধরন, প্রোফাইল, লিংক
- সংক্ষিপ্ত বিবরণ ও যোগাযোগ পেজ
- নোটিশ, সেবা, গ্যালারি
- মাধ্যমিক/ভোকেশনাল/উচ্চ মাধ্যমিক/BM পেজের ডাটা
- Advanced JSON editor দিয়ে অতিরিক্ত আইটেম যোগ/মুছা

মূল database:
storage/site-content.json

হোস্টিংয়ে storage/ এবং uploads/ ফোল্ডার writable রাখুন।


৭) গ্যালারি অ্যালবাম
- এডমিন প্যানেল থেকে “ওয়েবসাইট কনটেন্ট” খুলে “গ্যালারি” অংশে যান।
- প্রতিটি বক্সে Cover image এবং অ্যালবামের একাধিক ছবি আপলোড করা যাবে।
- একই বক্সে একাধিক ছবি সিলেক্ট করে আপলোড করলে Visitor বক্সে ক্লিক করার পর নতুন ট্যাবে ছবিগুলো পর্যায়ক্রমে দেখবে।
- image path/URL textarea-তে প্রতিটি লাইনে একটি করে ছবি path বা URL দেওয়া যাবে।

===============================
প্রফেশনাল ফুটার ব্যবস্থাপনা
===============================

- admin/content.php খুলে “ফুটার” অংশে যান।
- এখান থেকে ফুটারের পরিচিতি, Google Maps URL, গুরুত্বপূর্ণ লিংক, দাপ্তরিক লিংক,
  Facebook/YouTube URL, গোপনীয়তা নীতি, ব্যবহারের শর্তাবলি এবং কারিগরি ক্রেডিট পরিবর্তন করা যাবে।
- বিদ্যালয়ের নাম, EIIN, প্রতিষ্ঠাকাল, ঠিকানা, ফোন, ইমেইল ও অফিস সময় “মূল সেটিংস” অংশ থেকে নিয়ন্ত্রিত হবে।
- Facebook বা YouTube URL খালি রাখলে ভিজিটর পেজে ভুয়া/ডামি লিংক দেখানো হবে না।
- PHP API না থাকলে assets/js/site-settings.js ফাইলের SITE_FOOTER fallback edit করুন।


============================================================
শিক্ষার ধরন ও ১৬টি একাডেমিক তথ্যপেজ
============================================================

১. Admin panel → সম্পূর্ণ ওয়েবসাইট কনটেন্ট → একাডেমিক পেজ খুলুন।
২. প্রতিটি শিক্ষাস্তরের “ডান পাশের রঙিন তথ্য লিংক” ঘরে এই ফরম্যাট ব্যবহার করুন:
   আইকন | শিরোনাম | pages/ফাইলের-নাম.html
৩. Admin panel-এর “একাডেমিক তথ্যপেজ” অংশে ১৬টি পেজ আলাদাভাবে পাওয়া যাবে।
৪. টেবিলের কলাম একই লাইনে | দিয়ে আলাদা করুন।
৫. টেবিলের প্রতিটি নতুন সারি নতুন লাইনে লিখুন এবং সারির cell-গুলো | দিয়ে আলাদা করুন।
৬. Save করার পর সংশ্লিষ্ট visitor page reload করুন।
৭. সব পেজের হোম লিংক ../index.html এবং মূল শিক্ষাস্তরের লিংক pages ফোল্ডারের ভেতরে relative path ব্যবহার করে।
৮. মূল ডাটা storage/site-content.json-এ থাকে; storage/ writable না হলে পরিবর্তন সংরক্ষিত হবে না।

============================================================
সেবাসমূহের ১৫টি সাব-সেকশন ও ৫৯টি পৃথক পেজ
============================================================

১. Admin panel → “সেবাসমূহের পৃথক পেজ” খুলুন অথবা সরাসরি admin/service-pages.php ব্যবহার করুন।
২. Dropdown থেকে ৫৯টি পেজের যেকোনো একটি নির্বাচন করুন।
৩. সাব-সেকশনের নাম, পেজ title, hero-এর সংক্ষিপ্ত লেখা এবং বিস্তারিত তথ্য লিখে সংরক্ষণ করুন।
৪. PDF, DOC/DOCX, XLS/XLSX, PPT/PPTX, TXT/CSV, image অথবা ZIP file আপলোড করা যাবে।
৫. প্রতিটি file সর্বোচ্চ ১২ এমবি হতে পারবে।
৬. পেজের data storage/service-pages.json-এ সংরক্ষিত হয়।
৭. আপলোড করা file uploads/service-pages/ ফোল্ডারে সংরক্ষিত হয়।
৮. Hosting-এ storage/, uploads/ এবং uploads/service-pages/ writable রাখতে হবে।
৯. প্রতিটি visitor page pages/service-XX-YY.html path-এ রয়েছে এবং home/services navigation দেওয়া আছে।
